# 两版差异（实际玩过之后的记录）

对比方式：
- **HTML 版**：浏览器打开 <https://gagagacc.github.io/frontier-colony/>，实际走完「主菜单 → 选角色 → 选降落点 → 落地」并截图。
- **Godot 版**：`node tools/godot-shot.mjs` 拍下对应界面。

截图在 `tools/shots/`：`cmp-js-*.png`（HTML）与 `cmp-godot-*.png`（Godot）。

---

## 一、开局流程：HTML 有 4 步，Godot 只有 2 步

| 步骤 | HTML 版 | Godot 版 |
|---|---|---|
| 主菜单 | 标题 + **模式选择就在主菜单上**（开拓模式 / 纯塔防模式两个按钮 + 说明）+ 开始新开荒 / 存档管理 / 设置与操作说明 + 底部键位条 + 版本号 | 标题 + 开始游戏 / 设置 / 退出 + 继续存档 |
| 选角色 | **卡片式**：4 列大卡片，每张有图标头图、名号（结构工程师 · 拓荒序列 03）、台词、**「解锁专属建筑/武器」列表**、开场提示、属性格 | **文字列表**：每行「角色名 + 台词 + 一行属性 + 一行被动」 |
| **选降落点** | **整屏地图交互**：点地图选点、4 个推荐点按钮、右侧信息（坐标 / 生物群系 / 危险度 / 1000 内虫巢 / 资源丰度 ×1.25 / 地形危险 ×0.80 / 开阔度 57%）、底部图例（红点=虫巢 / 黄方块=废弃基地 / 紫方块=实验 vault） | **❌ 完全没有** —— 直接用世界生成的 `baseSite` 落地 |
| 落地 | 按选定坐标 | 自动 |

> 「选降落点」是**功能缺失**，不是美观问题：玩家少了一次「选择难度与资源」的决策。

## 二、游戏内 HUD：HTML 信息量大约多一倍

HTML 版顶部区（截图 `cmp-js-4-ingame.png`）：

1. 左上：**生命 + 经验条 + 蓝色条**，以及 **「第 1 天 · 黎明 · 00:20」**（昼夜与天数）
2. 顶部中：**局势面板** —— 「局势·平稳 | 第 1 波倒计时 02:09 | 后虫巢接近 · **威胁 185.6** · **活跃 42**」
3. 右上：**完整资源条** —— 金币 260 · 金属 90 · 晶体 0 · 食物 40 · 零件 10 · 研究资料 0
4. 顶部细条：**距离指示** —— 基地 4m · 载具 4.2m · 巢穴 33.1m
5. 世界内：基地血条 + 「拓荒级吸引阵列 LV.0 · 强度 28%」
6. 左下：小地图 + 「活跃 42 · 威胁 185.6」
7. 底部中：**8 格快捷栏**（图标 + 弹药数）
8. 右下：**可点击的面板按钮条** —— 科技[T] 城镇[G] 实验[V] 地图[M] 背包[Tab] 建造[B]
9. 右下角：键位提示

Godot 版（截图 `cmp-godot-1-world.png`）：

| 项目 | 状态 |
|---|---|
| 生命 / 弹药 / 射程 | ✅ 有 |
| 波次倒计时 | ✅ 有 |
| 阵列等级 / 燃料 | ✅ 有（右上） |
| 小地图 | ✅ 有 |
| **天数 / 昼夜时间** | ❌ 没有 |
| **威胁值 / 活跃怪物数** | ❌ 没有 |
| **完整资源条（金币/晶体/食物/零件/研究资料）** | ❌ 只在采集后显示采集到的几种 |
| **距离指示（基地/载具/巢穴）** | ❌ 没有 |
| **8 格快捷栏** | ❌ 没有（只有 4 个塔位圆点） |
| **右下可点击面板按钮条** | ❌ 没有（只能记键位） |

## 三、世界与美术

| | HTML | Godot |
|---|---|---|
| 地形 | 程序化色块 + 明暗档 | Kenney 贴图（64×64）+ 明暗档 ✅ 更细 |
| 基地平台 | 圆角矩形平台 + 描边 + 阵列环 | 圆形平台 + 核心舱 + 天线 ✅ 接近 |
| 怪物 | 程序化圆形 + 朝向楔形 | RTS 单位贴图 ✅ 更好看 |
| 载具 | 有车停在基地旁，可上车 | 有（`Vehicle`），但**开局是否可见与 HTML 一致待确认** |
| 掉落物 | 地上一颗颗可捡（截图里有黄点） | 有 `Props`，采集靠 E |

## 四、结论：差多少

**核心玩法与数值：基本一致**（这是移植的硬指标，5964 条断言 + 120 秒长时模拟逐位对比）。

**外围「玩家感」：差距明显**，按影响排序：

1. **缺「选降落点」整屏** —— 开局决策少一步（功能缺失）
2. **HUD 信息少一半** —— 天数、威胁值、活跃数、距离、完整资源条、快捷栏、面板按钮条（用起来「不知道现在什么情况」）
3. **选角色是文字列表**，HTML 是带图标与专属内容的卡片（第一印象差很多）
4. **主菜单缺模式选择入口**（HTML 直接摆在主菜单上）

## 五、建议的补齐顺序

| 优先级 | 事项 | 说明 |
|---|---|---|
| **P0** | 选降落点界面 | 复用 `world.find_open_spot` 与降落点评分（JS 有 `landingSites`），做成地图点击 + 推荐点按钮 |
| **P0** | HUD 补全 | 天数/昼夜、威胁值、活跃数、距离指示、完整资源条、8 格快捷栏 |
| **P1** | 右下角面板按钮条 | 鼠标可点，键位只是快捷键 |
| **P1** | 选角色卡片化 | 图标 + 专属内容列表 + 属性格 |
| **P2** | 主菜单加模式选择 | 与 HTML 一致，省一次点击 |

> 这些都在 Godot 仓库里做（`frontier-colony-godot`），HTML 版保持冻结。

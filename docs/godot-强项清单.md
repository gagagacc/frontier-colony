# Godot 引擎强项清单（哪些地方该「发挥引擎」而不是照搬 Canvas）

审计方式：把 JS 侧用到的能力与 Godot 侧逐项对照（`node` 扫关键词计数），
再挑**引擎确实更强**的地方做。纯功能缺失另列。

## 审计结果

| 能力 | JS 侧 | Godot 侧（改之前） | 结论 |
|---|---|---|---|
| 音频 | **122 处**（WebAudio 音效/音乐） | 3 处 | ❌ 基本是空的 |
| 光照 | 4 处（`drawLighting` 屏幕空间径向渐变） | **0 处** | ❌ 完全没有 |
| 粒子 | 0（手画 `effects.push({kind:'claw'})`） | 0 | ⚠️ 两边都手画，但 Godot 有 GPU 粒子 |
| 着色器 | 0 | 0 | ⚠️ 都没用；Godot 可用 |
| 震屏 / 顿帧 | 5 处 | ✅ 已补（CameraRig + hitstop） | 已对齐 |

## 已做：昼夜光照（`scripts/render/lighting.gd`）

**为什么这是引擎强项**：JS 的 `drawLighting` 只能在玩家周围糊一个黑色甜甜圈 ——
光源之间不会互相影响、照不亮地形细节、也没有暖冷色温。Godot 有：

- `CanvasModulate`：全局环境色，**随时间连续变化**（黄昏偏暖、夜里偏冷蓝）
- `PointLight2D`：真实点光源，**可叠加**、有柔和边缘（用程序化生成的径向渐变纹理，不引素材）
- 于是同时有：玩家视野光 + 核心舱光晕 + 枪口闪光，三者叠加而不是互相吞掉

黑暗曲线**照抄 JS**（`(time % 240) / 240` 再分段：0.45 前白天、0.58 入夜、0.92 转黎明），
保证「几点天黑」两边一致。截图 `tools/shots/night.png`：夜里核心舱的光洒在地形上。

另外补了 JS 的**红色警戒边框**（基地挨打/被毁时脉冲）—— 用 CanvasLayer + ColorRect，
不参与世界变换。

## 已做：HUD 补全（`scripts/ui/hud_extra.gd`）

天数/昼夜/时刻、局势（威胁值 + 活巢数）、完整资源条（带图标）、距离指示、8 格快捷栏。
公式全部照抄 JS（`_computeThreat`、`fmtTime`、相位阈值）。

## 已做：敌人拆基地/拆塔（`scripts/systems/structure_damage.gd`）

之前怪只打玩家 —— 「基地被摧毁 → 追杀 + 人口清零」这条主循环在 Godot 版走不到。
现在索敌规则照抄 JS（玩家在阵列里则建筑优先，否则谁近打谁）。

## 已做：选降落点（`scripts/ui/landing_map.gd`）

整屏地图交互：群系着色 + 巢穴红点 + 废弃基地黄方块 + 推荐点绿圈 + 7 项信息。
性能做法：世界 152×152 先烘成一张小图再放大画，比逐格 `draw_rect` 快两个数量级。

## 已做：音频系统（`scripts/systems/audio.gd`）

**审计出的最大空白**：JS 侧 122 处音效调用，Godot 侧几乎是静音的。现在用 Godot 的音频总线 + 播放器池：

- **SFX 总线**：音量设置直接作用在总线上，不必逐个播放器调
- **12 个播放器池**：同一音效连响不互相打断
- **变体随机 + 音高微抖**：同一动作不机械
- **距离衰减** `play_at()`：远处的命中声小一点，不混成一锅粥

素材：Kenney 的 CC0 音效包（impact / interface / sci-fi），拷了 **17 个** 进 `assets/audio/`
（开火轻重两套 / 命中 3 变体 / 爆炸 2 变体 / 建造 / 解锁 / 报错 / 脚步 4 变体 / 基地受击）。

## 已做：GPU 粒子（`scripts/render/effects.gd`）

JS 侧 0 处粒子（特效全靠手绘 `arc()`，每颗都是一次 CPU 调用）。现在用 `GPUParticles2D` + 程序化 8×8 柔光点贴图：

- 命中 → 小火花（8 颗，暖色）
- 击杀 → 大爆（精英 22 颗 / 普通 14 颗）
- 对象池 10 个发射器轮转，不每帧新建节点
